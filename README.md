# Vajraah Digital Website

Static website for Vajraah Digital, designed for GitHub Pages and the custom domain `vajraah.in`.

## Files
- `index.html` — complete responsive website
- `vajraah-logo.webp` — Vajraah logo/brand asset

## Publish
GitHub Pages → Settings → Pages → Deploy from branch → `main` / `/ (root)`.

## Custom domain
Add `vajraah.in` under GitHub Pages → Custom domain, then set DNS at your domain provider as instructed by GitHub.

## Contact form
The form currently posts to FormSubmit. Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want to receive enquiries at, then complete the first-time FormSubmit confirmation email.
